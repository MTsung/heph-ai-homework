# AI-LOG

## 系統設計

| 問題 | 處理方式 |
|---|---|
| App 輸入中文選字時按 Enter 會誤送出 | 照問題敘述給 AI 改 |
| 第一版架構有點 God Object | 重構，保留 request、response 結構的前提下 |
| 文件寫太複雜 | 叫 AI 留重點、易懂 |
| 資料夾很亂 | 題目、文件、程式分開放，名稱用英文 |
| 模型寫死不好換 | 用工廠模式，先接 Gemini，可以切換 |

## 後端

| 問題 | 處理方式 |
|---|---|
| 訂位原本是用爬蟲，會太死 | 改用 browser use，讓 AI 去判斷每個畫面該點什麼 |
| 怕 AI 亂填、亂按送出 | AI 只負責點選，填表跟最後送出交給程式核對 |
| 訂位條件一次問一堆又要慢慢打很難填 | 改成依序用點的點人數、日期、時段 |
| 等 AI 跑的時候不知道有沒有在動 | 加處理中提示 |
| 測備援時 Groq 也一直失敗，只顯示「目前系統有問題」 | 查 log 發現預設模型 llama-3.1-8b-instant 已被 Groq 下架，實測後預設改成 qwen/qwen3.8-27b |
